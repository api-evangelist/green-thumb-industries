## APIs

Green Thumb Industries does not publish a public developer portal, REST API, OpenAPI specs, or partner API documentation. GTI is a multi-state cannabis operator (RISE Dispensaries, Beboe, Dogwalkers, Good Green, Incredibles, RYTHM, Dr. Solomon's) and integrations with its retail and supply-chain systems (POS, e-commerce, seed-to-sale compliance) are arranged through vendor partnerships rather than via a self-service API.
